    ---
    项目整体结构：Causal_FMEA (因果FMEA推理引擎)

    一、文件夹分级

    causal_fmea_core/
    ├── Cargo.toml                          # Rust 项目配置
    ├── pyproject.toml                      # Python 打包配置 (maturin)
    ├── src/                                # Rust 底层核心 (编译为 Python 模块)
    │   ├── lib.rs                          # 主入口：PyO3 模块导出 + 引擎核心
    │   ├── dag.rs                          # 因果图数据结构
    │   ├── algorithms.rs                   # 图算法 (Kahn环检测 + 贝叶斯球d-分离)
    │   └── fmea_evaluator.rs              # FMEA SOD 评分计算
    ├── python/
    │   └── causal_fmea/                    # Python 上层逻辑
    │       ├── app.py                      # 主程序入口：LangGraph 状态机组装 + 运行
    │       ├── agent_state_machine.py      # 状态定义：数据类型 + Pydantic 输出约束
    │       ├── nodes.py                    # 工作节点：Generator(大模型) + Validator(Rust验证)
    │       └── context_guard.py            # 上下文管理器：Rust引擎生命周期 + 内存回收
    └── testpy/                             # 早期测试脚本
        ├── 1字符串转id.py
        ├── 2FMEA_SOD函数.py
        └── 3变量销毁_内存回收.py

    ┌───────────────────────────────────────────┬──────────────┬──────┬──────────────────────┐

    ┌────────────────────────────┬─────────────────────┬─────────────────────────┬───────────────────────────────────┐
    │         函数/结构          │        输入         │          输出           │               作用                │

    ├────────────────────────────┼─────────────────────┼─────────────────────────┼───────────────────────────────────┤
    │ get_node_name(&self,       │ usize               │ PyResult<Option<String> │ ID→字符串反向查询                 │
    │ node_id)                   │                     │ >                       │                                   │
    ├────────────────────────────┼─────────────────────┼─────────────────────────┼───────────────────────────────────┤

    └────────────────────────────┴─────────────────────┴─────────────────────────┴───────────────────────────────────┘

    内部机制:
    - LlamaMemoryReaper: 实现 Drop trait，引擎销毁时自动清理内存
    - interner: Arc<Mutex<IndexSet<String>>>: 线程安全字符串驻留池
    - 模块导出: causal_fmea_core.FmeaScore + causal_fmea_core.CausalParadigmEngine

    LangGraph状态机流程:
    1. 创建 StateGraph(CausalAgentState)
    2. 添加节点: generate_graph, validate_graph
    3. 固定边: START→generate_graph→validate_graph
    4. 条件边: validate_graph→should_continue→{generate_graph / END}

    五、数据流转总结

    场景文本 ─→ [Llama大模型+JSON约束] ─→ ExtractedGraph(Pydantic)
                                                │
                                                ▼
                                        [(source, target)] 边列表
                                                │
                                        ──FFI虫洞──
                                                │
                                                ▼
                                    [Rust] 字符串驻留池 → ID映射
                                    [Rust] CompactCausalGraph 建图
                                    [Rust] Kahn算法 环检测
                                                │
                                        ┌──────┴──────┐
                                        │             │
                                    通过✅        拦截🚨
                                        │             │
                                        ▼             ▼
                                    END      回滚+反思→重新生成

    核心设计: Python层(大模型推理+状态机编排) ↔ Rust层(图验证+内存安全)，通过PyO3桥接，AgentContext上下文管理器控制Rust引擎生命周期，确保每次验证后彻底回收内存。
